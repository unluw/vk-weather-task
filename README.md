# Weather Data

Небольшой Python-скрипт для получения текущей погоды в городах из файла `cities.txt`.

Программа получает данные через API wttr.in, выводит текущую температуру и страну для каждого города, а затем группирует результаты по странам и рассчитывает статистику.

## Возможности

- загрузка списка городов из `cities.txt`;
- удаление повторяющихся городов;
- получение данных через wttr.in;
- вывод города, страны и текущей температуры;
- группировка городов по странам;
- расчет средней, минимальной и максимальной температуры;
- обработка ошибок при получении данных.

## Требования

- Python 3
- подключение к интернету

Дополнительные библиотеки устанавливать не нужно — используются только стандартные модули Python.

## Запуск

1. Скачайте проект.
2. Убедитесь, что `cities.txt` находится в одной папке с `main.py`.
3. Откройте терминал в папке проекта.
4. Запустите:

```bash
python3 main.py
